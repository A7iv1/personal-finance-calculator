# # Калькулятор личных финансов

Простое консольное приложение на Python для учёта доходов и расходов с возможностью просмотра статистики.

## Описание
Приложение позволяет добавлять операции (доходы/расходы), указывать сумму, категорию и дату, а также просматривать текущий баланс и список всех операций. Данные сохраняются в локальном файле `data.json`.
